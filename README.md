# Azka Talat — Personal Portfolio Website

## 1. Introduction

The **Personal Portfolio Website** is a website designed to introduce Azka Talat, a Software Engineering student, and showcase her skills, education, and software development projects.

The main purpose of this website is to present personal and professional information in one place. It helps visitors learn about the developer, explore her projects, and find ways to contact her.

The website uses a modern **blue and lavender color theme** with a clean layout to provide a professional and user-friendly experience.

## 2. Project Objectives

The main objectives of this project are:

- To create a professional online presence.
- To introduce the developer and her educational background.
- To display technical skills and completed projects.
- To provide contact information for professional opportunities.
- To practice and demonstrate front-end web development skills.
- To create a website that works on desktop, tablet, and mobile screens.

## 3. Features

### Home Section
The home section introduces the developer with her name, professional title, a short introduction, and buttons for exploring projects or contacting her.

### About Me
This section provides information about the developer, her interests, and her journey as a Software Engineering student.

### Skills
The skills section presents the programming languages, technologies, and tools the developer has learned or used in her projects.

### Projects
This section displays selected projects with short descriptions and links to their source code on GitHub.

### Education
The education section highlights the developer's degree program and university.

### Contact
The contact section helps visitors connect with the developer for questions, collaboration, internships, or other professional opportunities.

### Responsive Navigation
The navigation menu helps visitors move between different sections of the website. On smaller screens, it adapts to provide a mobile-friendly experience.

### Animations and Visual Effects
Smooth scrolling, hover effects, and section reveal animations make the website more interactive and visually appealing.

### Modern Color Theme
The blue and lavender theme, white cards, and dark blue text create a consistent and readable design.

## 4. Technologies Used

### HTML5
HTML provides the structure of the website. It defines the headings, paragraphs, navigation links, project cards, buttons, and other page elements.

### CSS3
CSS controls the appearance of the website, including colors, fonts, spacing, layouts, animations, and responsive design.

### JavaScript
JavaScript adds interactive functionality, such as the mobile navigation menu, automatic copyright year, and animations when sections appear on the screen.

## 5. Featured Projects

### Eco Home Hub
Eco Home Hub is a website focused on sustainable living. It presents ideas and features related to household energy, water usage, waste management, eco scores, and sustainability goals.

### ShopEase
ShopEase is an e-commerce website interface designed to present products in an organized and user-friendly layout. It demonstrates front-end development concepts used in online shopping websites.

### NutritionAI Scanner
NutritionAI Scanner is a nutrition-focused application project that includes features such as food scanning, BMI calculation, water tracking, and user history.

These projects demonstrate practical application of programming, interface design, and problem-solving skills.

## 6. Project Structure

The project contains three main files:

```text
Portfolio/
├── index.html
├── style.css
└── script.js
```

- **index.html:** Contains the structure and content of the portfolio website.
- **style.css:** Defines the design, colors, layout, animations, and responsive styling.
- **script.js:** Handles interactive features and dynamic behavior.

## 7. How to Run the Project

Follow these steps to open the website on your computer:

1. Download or clone the repository from GitHub.
2. Open the downloaded project folder.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Double-click `index.html` to open it in a web browser.
5. Explore the different sections using the navigation menu.

No backend server or database is required to view the basic portfolio website.

## 8. Responsive Design

The website uses CSS Grid, Flexbox, and media queries to adjust its layout according to different screen sizes.

This allows visitors to view the portfolio on desktop computers, laptops, tablets, and mobile phones.
